The bar keeps its top-left corner clear only where the window controls sit there.

A native macOS window hides its title bar and lets the page draw to the top edge. The system then
paints its own close, minimise and zoom controls over the page's top-left corner. A page a browser
loads from the server build carries nothing there. One layout cannot serve both: space reserved
everywhere leaves the name starting at a position nothing explains, and space reserved nowhere leaves
the name under the controls.

The front end asks the framework's runtime once, at startup. `reservesWindowControls` in
`source/frontend/src/platform.ts` answers from three facts. The operating system is macOS, the
application is a desktop one, and the platform mode is not `server`. A page answering all three
carries the class `reserves-controls` on the application shell. That class alone widens the bar's
left padding.

The three facts hold each other up. The mode is the one that separates the two builds of the same
application on the same machine, since the server build alone reports `server`. The desktop and
macOS facts keep the corner clear of a window that has a title bar of its own to hold its controls.

## What holds

- A page reserves the corner only where the runtime reports macOS, a desktop application, and a mode
  other than `server`.
- A page that cannot reach the runtime at all reserves nothing, because a page with no runtime has no
  window controls painted over it.
- The name sits against the bar's own left edge wherever the page reserves nothing.

## What it costs

The two builds no longer look alike, so a reading taken in a browser does not settle what the window
shows. The rule reads three values the framework's runtime reports, and a release renaming any of
them returns the earlier fault rather than a refusal.

A window given a title bar of its own would need none of this, and it loses. It spends a strip of
window height on chrome carrying one word, and it puts a second bar directly under the one the
viewer draws.

Nothing follows from this on its own, which is what makes it terminal at capture.
