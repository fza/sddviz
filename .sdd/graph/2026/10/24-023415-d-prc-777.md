Every entry this repository captures goes through `agentic-capture <draft.md>`, and
`scripts/graph-capture.py` leaves the tree along with the `sddviz-sdd-capture` skill describing it.

The tool already does what the script did: it passes the body as one argument, runs one pre-flight,
and records that pre-flight with `--preflight-verified`. A second copy of the same pipeline kept here
drifts from the tool every agent uses in every other repository.

`.sdd/grounding.yaml` hands the tool the two rules specific to this repository. `listing_prefix: area-`
refuses a draft carrying no area. `draft_lint: python3 scripts/lint_draft.py` runs Vale over the body
and refuses on any finding, suggestions included, because a captured body cannot change.

The accepted cost is the medium finding. The script refused one before capture, while the tool
prints it and captures anyway. A medium finding that holds now costs a superseding entry rather than
a second run of the draft. The tool also checks for at least one area, where `AGENTS.md` asks for
exactly one, so whoever writes the draft holds that rule again.

The rejected alternative keeps the script beside the tool. Two pipelines answer the same draft in
two ways, and the one a session reaches for decides what lands.

Acceptance:

- The tree carries neither `scripts/graph-capture.py` nor `.claude/skills/sddviz-sdd-capture/`, and
  `AGENTS.md` names `agentic-capture` as the one way to capture.
- `scripts/lint_draft.py` exits 1 on a body carrying only a suggestion, and 2 when Vale is missing
  or refuses to run. `devbox run scripts:test` proves both, and `devbox run test` runs it.
