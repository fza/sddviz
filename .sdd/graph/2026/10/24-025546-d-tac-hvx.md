sddviz ships as the `sddviz` cask in `fza/homebrew-tap`, built by GoReleaser and versioned by
semantic-release. `fza/sddviz` is public, so the cask downloads from its releases with no token.

`.github/workflows/release.yml` runs the tests, then releases on a `macos-26` runner. It refuses to
build against an SDK older than 26, because the window's controls take their size from that SDK. Run
by hand from `main`, semantic-release picks the version from the commit types, creates the GitHub
release with its notes, and calls GoReleaser to add the archives. A pushed version releases
exactly that version through GoReleaser alone. The first release, `v0.0.1`, comes that way, because
semantic-release starts a fresh history at `1.0.0`.

Open-source GoReleaser builds no app bundle, so the archive carries one. The build writes the binary
to `sddviz.app/Contents/MacOS/sddviz` for `arm64` and `amd64`. The archive adds a copy of
`Info.plist` stamped with the release version and a minimum system of 14.0, plus the icon. The cask
installs `sddviz.app` and links the binary onto `PATH`. Before Homebrew moves the bundle, the cask
clears its quarantine flag and signs it ad hoc, since it carries no Developer ID signature.

`HOMEBREW_TAP_TOKEN` writes the cask. A prerelease version leaves the tap alone.

The release configuration names `source/bin/release`, which exists only while a release builds. The
path check in `scripts/lint/refs.py` therefore skips any path git ignores, since build output is
absent from every fresh clone.

Rejected: releases on the private repository behind a token-reading download strategy, which calls
a Homebrew internal API and serves only readers holding a token. A separate public repository holding
only releases, which splits the notes from the code. GoReleaser Pro for its bundle and disk image
support, a paid licence for what the archive layout already does.

The accepted cost is Gatekeeper. Without a Developer ID certificate and notarization, the cask
bypasses the check that would otherwise vouch for the bundle.

Acceptance:

- A snapshot release builds both archives. Each holds `sddviz.app` with the versioned `Info.plist`,
  the icon, and a binary linking only system libraries.
- The bundle, signed ad hoc as the cask does, passes `codesign --verify --deep --strict`. It opens a
  window when launched directly and when launched through a link.
- `semantic-release --dry-run` reads the configuration and plans a release.
