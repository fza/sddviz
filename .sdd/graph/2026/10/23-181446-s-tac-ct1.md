The viewer never reads a graph's schema version, so it reads a format it was not written for without saying so.

`AGENTS.md` states that the store knows the entry format for a stated `graph_schema_version` and reports an unknown one rather than guessing. No code reads `.sdd/meta.json`, and no Go or TypeScript file names the field. The store decodes every entry's frontmatter into a map and picks known keys from it.

## What it costs

This repository's graph now states schema 2, while the embedded sdd `v0.16.2` knows schema 1 alone. The viewer opens it without a word. Nothing tells a reader that a field the newer format added goes unread. A field the newer format renamed or reshaped would show up empty or wrong, and nothing would point at the cause.

The rule in `AGENTS.md` claims a guard the code lacks, so a reader trusting it believes the viewer refuses what it actually accepts.
