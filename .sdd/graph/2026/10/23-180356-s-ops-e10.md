The repository no longer tracks the go-task checksum cache under `source/.task/`, and `.gitignore` now excludes it.

go-task writes a checksum file for each task it runs, so it can skip a step whose inputs did not change. Those files describe one machine's last build and mean nothing to another reader. Git tracked six of them, so every local build left the working tree dirty.

The fix removes the folder from the git index and adds `source/.task/` to the derived state block of `.gitignore`. The files stay on disk, so go-task still skips unchanged steps. Commit `fe412cb` carries the change.
