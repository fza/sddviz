A reader who closes the repository in the server build cannot open one again.

The bar carries a control that lets go of the open repository, and both builds show it. After it, the main area offers one control, which asks for a directory through the native picker. A server build carries no native dialogs, so `ChooseRepositoryDirectory()` answers with `ErrNoWindowSystem`. The command-line argument is the server build's only other way in, and it acts once, at startup.

## What it costs

A reader in a browser who presses that control loses every way back in. Only a restart of the server process brings the graph back. The desktop build keeps its picker and works as before.
