sddviz is a Tauri v2 desktop application built from two peer modules under `source/`: `ui`, React 19 and TypeScript on Vite, and `backend`, a Rust crate carrying `tauri.conf.json`. The Tauri command interface is the only path between them, and neither module imports from the other's tree.

The toolchain is pinned in `devbox.json` (Node.js 24, rustup) and driven through `devbox run` scripts. macOS is the only exercised target. `sdd` on `PATH` at 0.16.2 or later supplies search and linting; browsing a graph works without it, with those features absent.

`README.md` carries setup and commands, `docs/index.md` the module layout and boundaries.
