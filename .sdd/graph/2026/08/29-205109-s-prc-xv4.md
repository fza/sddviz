sddviz is a Wails v3 desktop application: one Go module at `source/`, holding a React 19 and
TypeScript web application at `source/frontend`.

The web application sits inside the Go module because `go:embed` reaches nothing outside its own
package directory. Vite builds it into `source/frontend/dist`, and the module embeds that. One path
joins the two halves: a Wails service, reached through the bindings `wails3 generate bindings`
writes and the repository commits.

sddviz embeds sdd as a library rather than calling it as a tool, so a reader installs nothing
alongside the application, and `go.mod` pins the version it reads.

`devbox.json` pins the toolchain: Go 1.26, Node.js 24, `golangci-lint` and `go-task`, driven through
`devbox run` scripts. `devbox run tools` adds the Wails command line. The repository allows CGO, and
a desktop build needs it to bind the system WebView. A server build, `go build -tags server`, makes
the same application serve HTTP and needs no CGO. macOS is the one target anyone exercises.

`README.md` carries setup and commands. `docs/index.md` carries the layout and the module
boundaries.
