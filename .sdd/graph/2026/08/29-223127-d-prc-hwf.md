This repository holds its prose to a linter and its references to checks, and both run in
`devbox run lint`.

`docs/rules.md` fixes the vocabulary. Words for what the graph holds are SDD's own, spelled as SDD
spells them. A reader who also uses the tool would otherwise meet two names for one thing. That
licence stops at the graph, and everything sddviz builds of its own takes a name the document
decides. `.vale/styles/Taxonomy/` carries the checkable half, and that set earns each entry.

Six checks in `scripts/lint/refs.py` assert what no other tool sees. Three follow pointers: a bare
tree path a file names, a relative link a document writes, and a code identifier a document claims
this tree carries. Three hold the vocabulary itself. The rules document and the checks must name the
same forms. A banned-word rule must report the word it bans. No accepted term may name code rather
than a word.

The probe over the banned-word rules matters most. A token that silently stops matching passes every
document, so each rule carries lines it must report beside lines it must leave alone. A guard nobody
can see fail is worth nothing.

Nine checks ship in the repository these derive from. The three left behind assert things this
project does not have: numbered documentation sets to cite into, its own retired vocabulary, and a
roster of packages that several modules carry.

Nothing follows from this on its own. It binds work other entries commission.
